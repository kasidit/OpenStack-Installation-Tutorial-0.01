บทที่ ๐ การติดตั้งระบบโอเพนสแตค

การติดตั้งโอเพนสแตคแบบ Multi-node บนเครื่องโฮสต์ 4 เครื่องด้วย Kolla Ansible

การติดตั้งระบบโอเพนสแตคมีความซับซ้อนพอสมควรเนื่องจากโอเพนสแตคถูกสร้างขึ้นบนซอฟต์แวร์โอเพนซอร์ส หลายซอฟต์แวร์และสามารถติดตั้งได้หลายรูปแบบ ที่ผ่านมากลุ่มผู้พัฒนาและใช้งานโอเพนสแตค (OpenStack Community) ได้นำเสนอวิธีการติดตั้งหลายวิธีบนระบบปฏิบัติการลินุกซ์ ที่เป็นที่นิยมได้แก่

  1. ใช้ซอฟต์แวร์ Kolla Ansible ซึ่งถูกพัฒนาขึ้นโดยใช้ docker container และ ansible playbook ที่

https://docs.openstack.org/kolla-ansible/latest/user/quickstart.html

  1. ติดตั้งด้วยคำสั่ง Command Line ตามคู่มือที่ https://docs.openstack.org/install-guide/

  2. ติดตั้งด้วยซอฟต์แวร์ MicroStack หรือ sunbeam หรือ Charm ของบริษัท Cannonical (ผู้สร้าง Ubuntu Linux) MicroStack และ sunbeam เป็นซอฟต์แวร์ที่ใช้งานง่ายและถูกใช้เพื่อติดตั้งโอเพนสแตคบนระบบคอมพิวเตอร์ของบริษัทขนาดกลางหรือเล็กที่มีทรัพยากรไม่มาก ในขณะที่ Charm มีความซับซ้อนมากกว่าและใช้สำหรับติดตั้งโอเพนสแตคในศูนย์ข้อมูลขนาดใหญ่

นอกจากนั้นยังมีวิธีการติดตั้งของอื่นๆเช่น Rackspace Mirantis และ Red Hat เป็นต้น

หนังสือฉบับนี้สอนวิธีการติดตั้งโดยใช้ Kolla Ansible เป็นวิธีการที่ง่ายและใช้กันอย่างแพร่หลาย และจะสอนการติดตั้งโดยใช้ Shell Scripts ที่สร้างขึ้นจากคำสั่ง Command Line ตามคู่มือของโอเพนสแตคในภาคผนวก ก

๐.1 การเตรียมคอมพิวเตอร์และระบบเครือข่าย

หนังสือฉบับมีวัตถุประสงค์ที่จะบรรยายการติดตั้งระบบโอเพนสแตคแบบที่ใกล้เคียงกับการใช้งานจริงของบริษัทหรือองค์กรขนาดเล็กที่มีทรัพยากรดังภาพ ๐-1 ซึ่งประกอบไปด้วยโฮสต์คอมพิวเตอร์และระบบเครือข่ายต่อไปนี้

  1. มีเครื่องโฮสต์ 4 เครื่องทุกเครื่องติดตั้งระบบ Ubuntu 22.04 เพื่อติดตั้งโอเพนสแตคเวอร์ชัน Caracal

  2. เครื่องโฮสต์ประกอบไปด้วย เครื่อง controller node 1 เครื่อง network node 1 และ เครื่อง compute node 2 เครื่อง โดยที่เครื่องหนึ่งจะมีพื้นที่เก็บข้อมูลที่จะถูกใช้เป็นที่เก็บข้อมูลแบบ Block Storage เราเรียกเครื่อง compute node เครื่องนี้ว่า storage node

กำหนดให้เครื่องโฮสต์ทั้ง 4 เครื่องมีชื่อและ Specification ขั้นต่ำดังตาราง ๐-1

ภาพ ๐-1 ผู้ติดตั้งต้องกำหนดค่า configuration ของเครื่องโฮสต์ทั้ง 4 ดังนี้

1. เครื่อง controller host : ชื่อ controller01 มีบัญชีสำหรับติดตั้งชื่อ openstack ซึ่งต้องมีบัญชีชื่อนี้บนเครื่องโฮสต์ทุกเครื่อง และบัญชีนี้บนทุกเครื่องต้องสามารถใช้คำสั่ง sudo ได้โดยไม่ต้องใส่ password เครื่อง controller เชื่อมต่อกับ Management Network ทาง NIC ens3 โดยกำหนดให้มีค่าไอพีแอดเดรสคือ 172.16.81.11 และกำหนดให้เมื่อติดตั้งโอเพนสแตคแล้วค่า IP address เสมือน (VIP address) สำหรับเจ้าถึง Dashboard ของโอเพนสแตค คือ 172.16.81.254 ผ่าน Management Network (ในกรณีที่ผู้ติดตั้งต้องการให้ผู้ใช้เข้าถึง Dashboard ทาง Network อื่นเพื่อรักษาความปลอดภัยก็สามารถทำได้เช่นกัน แต่ในหนังสือนี้เราจะเข้าถึง Dashboard ทาง Management Network เพื่อความง่ายในการอธิบาย)

ในกรณีที่ผู้ใช้ต้องการให้เครื่อง controller สามารถติดต่อกับระบบเครือข่าย External Network ที่โอเพนสแตคใช้เชื่อมต่อวีเอ็มภายในกับระบบอินเตอร์เน็ตเพื่อทดสอบวีเอ็ม (ผู้ใช้สามารถลบทิ้งภายหลังได้เพื่อป้องกันไม่ให้วีเอ็มสามารถเข้าถึงเครื่อง controller ) ผู้ใช้สามารถกำหนดให้ Nic อีกอันหนึ่ง เช่น ens4 ของ controller เชื่อมต่อกับ External Network และกำหนดค่า IP address เช่น 10.81.1.99 ดังภาพ

2. เครื่อง network host: ชื่อ network01 เป็นเครื่อง network node มีบัญชีสำหรับติดตั้งคือ openstack มี NIC สามอัน โดยที่ NIC ens3 มีไอพีแอดเดรสคือ 172.16.81.21 ติดต่อกับ Management Network และ NIC ens4 มีไอพีแอดเดรสคือ 192.168.81.21 ติดต่อกับ Data Tunnel Network และ NIC ens5 ไม่ต้องมีไอพีแอดเดรส ติดต่อกับ External Network

3. เครื่อง compute และ storage host: ชื่อ compute01 เป็นเครื่อง compute และ storage node มีบัญชีติดตั้งชื่อ openstack มี NIC สองอัน โดยที่ NIC ens3 มีไอพีแอดเดรสคือ 172.16.81.31 ติดต่อกับ Management Network และ NIC ens4 มีไอพีแอดเดรสคือ 192.168.81.31 ติดต่อกับ Data Tunnel Network ในเครื่องนี้จะมี Block Storage คือ disk หรือ ssd ชื่อ /dev/sdb

4. เครื่อง compute: ชื่อ compute02 เป็น compute node อย่างเดียว มีบัญชีชื่อ openstack มี NIC สองอัน โดยที่ NIC ens3 มีไอพีแอดเดรสคือ 172.16.81.32 ติดต่อกับ Management Network และ NIC ens4 มีไอพีแอดเดรสคือ 192.168.81.32 ติดต่อกับ Data Tunnel Network

จากภาพ ๐-1 ผู้ติดตั้งจะต้องจัดเตรียมระบบเครือข่ายที่มีการเชื่อมต่อเครื่องคอมพิวเตอร์ทั้ง 4 เครื่องดังนี้

  1. Management Network: เป็นระบบเครือข่ายสำหรับให้ซอฟต์แวร์ส่วนประกอบของโอเพนสแตคบนเครื่องโฮสต์ทุกเครื่องใช้สื่อสารคำสั่งและข้อมูลเพื่อปฏิบัติงาน นอกจากนั้นยังใช้สำหรับการติดตั้งโอเพนสแตคด้วย ในกรติดตั้งนี้ Management Network มี subnet address คือ 172.16.0.0/16

  2. Data Tunnel Network: เป็นระบบเครือข่ายที่โอเพนสแตคใช้สำหรับสื่อสารข้อมูลระหว่างวีเอ็มที่รันบนต่างเครื่องโฮสต์ และระหว่างวีเอ็มกับเร้าเต‍อร์เสมือนที่อยู่บนเครื่องเน็ตเวิร์คโฮสต์ เร้าเต‍อร์เสมือนจะทำหน้าที่ส่งผ่านข้อมูลของวีเอ็มออกสู่ระบบเครือข่ายภายนอกและส่งผ่านข้อมูลจากระบบเครือข่ายภายนอกให้วีเอ็ม ในภาพระบบ Data Tunnel Network มี subnet address คือ 192.168.81.0/24

  3. External Network: เป็นระบบเครือข่ายที่โอเพนสแตคใช้สื่อสารกับโลกภายนอก องค์กรจะต้องจัดสรรหมายเลขไอพีจำนวนหนึ่งจากเครือข่ายนี้มาเป็น Floating IP สำหรับทำ DNAT ให้กับวีเอ็มภายในระบบโอเพนสแตค ในการติดตั้งนี้ External Network มี subnet address คือ 10.81.1.0/24 และ Floating IP คือค่า IP ตั้งแต่ 10.81.1.100 ถึง 10.81.1.200

ผู้เขียนได้พัฒนาเว็บเพจสำหรับแนะแนวการติดตั้งโอเพนสแตคด้วยซอฟต์แวร์ kolla ansibleซึ่งใช้ ด็อกเกอร์ และแอนสิเบิ้ลเป็นเครื่องมือในการติดตั้งที่เว็บไซด์ https://vasabilab.github.io/kolla_helper_4nv1.html เว็บเพจนี้แสดงแผนภาพที่สร้างขึ้นด้วยจาวาสคริปต์ (javascript) เพื่อให้ผู้ใช้กรอกค่าพารามิเตอร์สำหรับติดตั้งดังภาพ ๐-2 ซึ่งความหมายของแต่ละช่องแสดงในตาราง ๐-2

ผู้ติดตั้งสามารถกรอกค่าพารามีเตอร์ในตาราง ๐-2 ดังต่อไปนี้ (ตาราง ๐-3)

๐.2 การติดตั้งโอเพนสแตคด้วย kolla ansible

ให้ใส่ค่าพารามิเตอร์สำหรับคอนฟิกุเรชันของเครื่องโฮสต์ทั้ง 4 ที่เว็บไซด์ OpenStack kolla-ansible helper ดังภาพ ๐-3 แล้วกดปุ่ม “Generate Tutorial” เว็บเพจจะสร้างคำแนะนำดังต่อไปนี้ (หมายเหตุ: หากค่าพารามิเตอร์ที่กำหนดผิดพลาด เว็บเพจจะแสดงผลว่า “Network Verification Results: Pass” หรือ “Network Verification Results: Fail” ในกรณีที่ Fail ให้กดปุ่ม “Click to view verification details” เพื่อดูคำอธิบาย) ผู้ติดตั้งสามารถดู playlist การติดตั้งได้ที่ OpenStack kolla-ansible installation playlist และทำตามขั้นตอนต่อไปนี้

๐.2.1 เตรียมความพร้อมของเครื่องโฮสต์ที่จะติดตั้งระบบโอเพนสแตค

ผู้อ่านควร ตรวจสอบว่าระบบลินุกซ์ที่ใช้คือ Ubuntu 22.04 ซึ่งมีเคอร์เนิลแบบ Linux Generic แทนที่จะเป็นแบบ linux-kvm (เคอร์เนิลแบบ Linux-kvm เป็นแบบที่ได้รับการปรับแต่งให้รันวีเอ็มได้เร็วจึงมีการตัดบางโมดูลออก) ซึ่งบางโมดูลที่โอเพนสแตคใช้เช่น ip_vs ไม่มีอยู่ใน linux-kvm นอกจานั้น บนเครื่อง controller01 ผู้อ่านต้องใส่ชื่อโฮสต์ทุกเครื่องในไฟล์ /etc/hosts

On every host
$ uname -a
Linux ...-generic... <-- generic is recommended
$ sudo apt update; sudo apt dist-upgrade
$ test -f /var/run/reboot-required && sudo reboot

On controller01 host:

$ cat /etc/hosts
 ...

172.16.81.21 network01
172.16.81.31 compute01
172.16.81.32 compute02
 ...
$

หลังจากนั้นทำสิ่งต่อไปนี้

  1. สร้างคู่ private/public keys แบบไม่ต้องใส่ passphrase เพื่อความสะดวกในการติดตั้ง

  2. กระจาย public key บนทุกเครื่องโฮสต์ด้วยคำสั่ง ssh-copy-id และเช็คว่าผู้อ่านสามารถ remote ssh จาก controller01 เข้าสู่เครื่องโฮสต์อื่นโดยไม่ใส่ password หรือ passphrase

  3. ล็อกอินทางไกลเข้าสู่เครื่่อง network01 compute01 และ compute02 ด้วย ssh แล้วอัพเดท Linux ดังที่เคยทำบนเครื่อง controller01

  4. ใช้ ping ทดสอบการเชื่อมต่อระหว่างเครื่องโฮสต์ ผ่าน data tunnel network และ

  5. ทดสอบการเชื่อมต่อจากเครื่อง network01 ไปยัง external network (สมมุติว่า 10.81.1.222/24 คือค่า IP address ใน subnet 10.81.1.0/24 ที่ว่างอยู่ ยังไม่ถูกใช้งาน มันจะถูกใช้ในการทดสอบนี้ชั่วคราวแล้วถูกลบออกไป)

๐.2.2 ติดตั้ง Kolla Ansible

บนเครื่อง controller01 สร้าง virtual environment และออกคำสั่งภายใน virtual environment ขอให้สังเกตุว่า command line prompt จะเปลี่ยนเป็น (kolla-ops) openstack@controller01:~$ ซึ่งเราจะย่อเป็น (kolla-ops)...:~$ เพื่อความสะดวกในการเขียน

Terminal
$ cd $HOME
$ mkdir $HOME/kolla-ops
$ python3 -m venv $HOME/kolla-ops
$ source $HOME/kolla-ops/bin/activate
(kolla-ops) openstack@controller01:~$
(kolla-ops)...:~$
